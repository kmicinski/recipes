Not food — the containers this prep week runs on. Planned onto the prep day so they land on the shopping trip automatically.

- **Food storage containers:** one meal-prep set (glass snapware-style or the divided plastic meal-prep packs Costco carries). Enough for rice + veg + protein bowls for two, ~4 days.
- **Small dip containers:** for portioned tzatziki so lunches are genuinely grab-and-go. If Costco's aisle doesn't have small ones that day, any 2-4 oz condiment cups from a grocery run work.

Delete this from a future week's plan if you don't need more containers.
